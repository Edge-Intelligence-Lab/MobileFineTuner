# Qwen3.5 pure-text validation — 2026-11-15

Qwen3.5-0.8B pure-text LoRA is implemented locally on top of upstream
`be95a289d9cd5ecd93b6fab7fdc3c4551c3f9fb1` plus the Qwen2/Qwen3/GPT-2 fixes
recorded in [the preceding report](QWEN_20261115.md). Branch:
`validation/macos-20261114`. Changes are uncommitted and have not been pushed.

## Implemented scope

- Configuration-driven `qwen3_5_text` decoder and extraction of the text backbone
  from full `qwen3_5` snapshots. Both `model.*` and `model.language_model.*` base
  tensor namespaces are supported, with strict shape/key checks.
- Per-layer dispatch between Gated DeltaNet (causal depthwise convolution,
  normalized Q/K, gated delta recurrence, gated RMS normalization) and gated
  full attention (doubled Q projection, Q/K norms, partial default RoPE, GQA).
- Zero-centered decoder/QK normalization, common SwiGLU MLP and tied/untied heads.
- Exact LoRA suffix targets across heterogeneous layers, including all-linear;
  standard text-only PEFT adapter import/export and failed-load atomicity.
- CPU FP32 forward and reverse-mode derivatives for the new kernels. Frozen
  BF16/F16 matrices can be retained by the example's native storage policy;
  convolution and normalization parameters stay FP32.
- Large-vocabulary dense/streaming cross-entropy backward now accumulates the
  softmax denominator in double precision, matching its forward policy. The
  previous float accumulation produced material error with 248,320 classes.
- Fixed the Qwen MMLU example's missing Linux/Android `unistd.h` include.

This covers full-sequence **text LoRA**. Vision/image/video inputs, MoE,
incremental caches, and Qwen3.5 parameter offload/checkpointing are outside the
validated implementation. Offload/checkpoint requests are rejected explicitly.
The recurrent backward retains state at each token; long-sequence phone memory
and sustained training quality have not been qualified.

## Numerical checks

Four independent tiny reference models cover tied/untied heads, mixed layer
orders, grouped linear-attention heads, unequal K/V dimensions, partial RoPE,
all-linear/exact target selection, padding, and a 67-token case that crosses the
reference's 64-token delta-rule chunk boundary. Each is checked with both
ordinary and streamed full attention, for eight comparisons.

- Every logit, every LoRA A/B gradient, one Adam update, post-update logits,
  native reload, PEFT-to-native and native-to-PEFT evaluation pass.
- Before the large-vocabulary loss precision fix, maximum tiny logit error was
  `2.98023e-8`, gradient error `6.98492e-10`, and Adam weight error `1.00955e-6`.
  All eight cases were rerun and pass with the final loss implementation.
- Finite differences independently check causal convolution (input and kernel),
  partial RoPE, and all seven delta-rule inputs, including grouped Q/K heads.
  Maximum absolute derivative difference: `2.474e-5` at perturbation `1e-3`.
- A closed-form 248,320-class loss case verifies target gradients and additive-
  shift invariance in dense loss, plus the streaming hidden-state gradient.

The **official full 0.8B model** is checked against HF/PEFT with nonzero initial
A and B on two four-token sequences, including a padding mask. All 372 adapter
tensors are checked; none are omitted.

| Full-model check | Ordinary full attention | Streamed full attention |
| --- | ---: | ---: |
| Maximum logit absolute error | 6.38962e-5 | 6.00219e-5 |
| Maximum gradient absolute error | 4.59671e-4 | 4.64439e-4 |
| Maximum SGD weight absolute error | 4.60073e-7 | 4.65661e-7 |
| Post-update logits / native reload / PEFT adapter | Pass | Pass |

Tiny-coordinate tolerances are logits `3e-5 + 3e-4*abs(ref)`, gradients
`2e-6 + 3e-3*abs(ref)`, and updates `2e-6 + 3e-4*abs(ref)`.
Full-model logits use `1e-3 + 1e-4*abs(ref)`. Every full-model gradient tensor
must satisfy both relative L2 error below `5e-4` (plus `1e-7` absolute allowance)
and maximum error below `1e-3*max(abs(ref)) + 1e-6`. This accounts for FP32
reduction-order differences in the deep graph without accepting an unchecked
small-gradient tensor. The maximum observed relative L2 error in the ordinary
full-attention diagnostic was `2.646e-4`.

Full-size cross-framework update comparison uses **SGD, lr=1e-3**. An exploratory
Adam/eps=1e-8 comparison did not meet the tiny-model coordinate and post-update
logit tolerances: small differences around cancelled gradients can be amplified
by Adam's normalization. Full-size Adam trajectory parity is not claimed.
Tiny-model Adam alignment and the full native Adam training/resume checks below
are separate evidence. The acceptance tolerances and optimizer are recorded in
the generator/test source and protocol files.

## Official-weight Mac training

WikiText-2 excerpt, sequence length 16, batch size 1, rank 3, alpha 6,
LoRA dropout 0, all-linear targets, default Adam and gradient clipping. In this
historical run, the CLI retained BF16 dense matrices but promoted linear-mixer
projections to FP32. The PR integration audit subsequently unified native storage
for all frozen matrices and separately checked that policy against the official
weights; the old run is not an all-BF16-matrix result:

| Run | Step 1 loss | Step 2 loss | Step 3 loss |
| --- | ---: | ---: | ---: |
| Initial training | 6.90106 | 5.6950 | 6.1198 |
| Resume adapter with a fresh optimizer | 6.20688 | 5.1345 | 5.6464 |

All 186 B matrices are finite and nonzero, spanning both mixer types and MLPs.
The saved adapter has 372 tensors. All 372 tensors change on resumed training.
PEFT loads both saved adapters with bitwise-equal tensor values. These are
short correctness checks on differing minibatches, not a convergence or model-
quality benchmark. Resume restores adapter weights/config, not optimizer state.
The official tokenizer passes nine HF golden cases.

## Reproduce

```bash
python3 -m venv runs/qwen35/venv
runs/qwen35/venv/bin/pip install -r scripts/requirements-qwen35-validation.txt
runs/qwen35/venv/bin/python scripts/generate_qwen_hf_fixtures.py \
  --qwen35 --output runs/qwen35/fixtures
MFT_QWEN_HF_FIXTURES="$PWD/runs/qwen35/fixtures" \
  ctest --test-dir operator/build --output-on-failure -R 'Qwen|LMLossLarge'
runs/qwen35/venv/bin/python scripts/generate_qwen_hf_fixtures.py \
  --qwen35 --real-model "$QWEN35_MODEL_DIR" --real-gradients \
  --reference-optimizer sgd --output runs/qwen35/real_fixtures --name qwen35_official
operator/build/test_qwen_hf_parity runs/qwen35/real_fixtures
runs/qwen35/venv/bin/python scripts/generate_qwen_hf_fixtures.py \
  --output runs/qwen35/real_fixtures --verify-native

examples/qwen_lora_finetune/build/train_wikitext \
  --model_dir "$QWEN35_MODEL_DIR" --data_dir "$WT2_DATA_DIR" \
  --seq_len 16 --batch_size 1 --max_steps 3 \
  --lora_r 3 --lora_alpha 6 --lora_dropout 0 --lora_targets all-linear \
  --output_dir runs/qwen35/real_train
```
